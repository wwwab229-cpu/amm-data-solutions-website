# AMM Data Solutions Website

Modular Next.js foundation for AMM Data Solutions.

## Structure principles
- Keep each major page section in its own component.
- Keep website copy and service data separate from layout code.
- Centralize design tokens and animation styles.
- Store images and logos in `public/`.
- Build responsive, reusable components.

## Local development
1. Install Node.js LTS.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

This is a starter foundation. Final design details and approved service wording will be refined after reviewing the supplied references and source code.
